# Security Policy

## Reporting Security Issues

This repository contains educational guides only — no production code or infrastructure.

If you find an issue with the guides (incorrect commands, security-related mistakes), please open a GitHub Issue.

## What is NOT in this repository

- No private keys
- No server IP addresses  
- No UUIDs or credentials
- No API tokens
- All config examples use placeholder values only

## Responsible Use

This guide is intended for legal privacy protection purposes. Use it to:
- Protect your privacy online
- Access legally available content in your region
- Secure your connection on public Wi-Fi

Please comply with the laws of your country.
