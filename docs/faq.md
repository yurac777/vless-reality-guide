# ❓ FAQ — Частые вопросы и решения

## Общие вопросы

### Чем VLESS Reality лучше обычного VPN?

Обычный VPN (WireGuard, OpenVPN, L2TP) **виден на уровне DPI**. ТСПУ видит характерные паттерны и блокирует или замедляет соединение.

VLESS Reality маскируется под обычный HTTPS-трафик к таким сайтам как Apple или Microsoft. На уровне ТСПУ выглядит как обычный браузер, заходящий на легальный сайт.

### Насколько это безопасно?

Шифрование аналогично TLS 1.3 — тому, что использует весь HTTPS-интернет. Ваш трафик зашифрован между вашим устройством и VPS. Дальше он выходит в интернет уже с IP вашего VPS.

### Могут ли заблокировать мой сервер?

Теоретически да — РКН может заблокировать IP вашего VPS. Но:
- VLESS Reality практически невозможно обнаружить автоматически
- Блокировки отдельных VPS происходят редко и только по жалобам
- Если заблокируют IP — просто смените IP у хостера (UUID и ключи остаются)

### Сколько пользователей выдержит один VPS?

## Проблемы с подключением

### Не могу подключиться вообще (timeout)

1️⃣ Проверьте, открыт ли порт 443 на сервере:
```bash
# На сервере
ufw status | grep 443
# Или
netstat -tlnp | grep 443
```

2️⃣ Проверьте, запущен ли XRay:
```bash
systemctl status xray
```

3️⃣ Проверьте логи XRay:
```bash
journalctl -u xray -n 50 --no-pager
```

4️⃣ Проверьте с другого устройства или сети — проблема может быть в вашем провайдере.

### Подключается, но YouTube грузит медленно

- Включите split tunneling: российский трафик напрямую, иностранный через VPN
- Выберите сервер поближе (Финляндия/Латвия быстрее чем США для России)
- Проверьте скорость сервера: `speedtest-cli` на VPS

### Работает только HTTP, не HTTPS

В конфиге клиента проверьте что `security: reality` указан правильно. Убедитесь что `publicKey` и `shortId` скопированы без пробелов.

### Не работает на МТС мобильном / Теле2

МТС и Теле2 применяют агрессивный DPI на мобильном трафике. Попробуйте:

1. Поменять `dest` в Reality с `www.apple.com:443` на `www.microsoft.com:443` или `addons.mozilla.org:443`
2. Поменять `fingerprint` с `chrome` на `firefox` или `safari`
3. Попробовать другой VPS (другой хостинг, другой IP)

### Работает дома, не работает в офисе

Корпоративные сети часто используют свой DPI и SSL-инспекцию. В этом случае:
- Попробуйте подключение через мобильный интернет как hotspot
- Или используйте клиент с TUN-режимом (перехватывает весь трафик, включая мобильные приложения)

### Нужен ли домен?

Нет — VLESS Reality работает по IP. Домен полезен только если хотите ещё и сайт на том же сервере.

### Можно ли использовать IPv6?

Да — VLESS поддерживает IPv6. В клиенте укажите IPv6-адрес сервера в квадратных скобках: `[2a01:4f8::1]`.

## Вопросы о клиентах

### Какой клиент самый лучший для Windows?

**v2rayN** — лучший выбор для большинства пользователей. Активно обновляется, поддерживает все протоколы, есть TUN-режим.

### Какой клиент для macOS?

- **Hiddify** (бесплатно) — [GitHub](https://github.com/hiddify/hiddify-app)
- **V2Box** (бесплатно) — App Store
- **Streisand** — App Store (тот же что на iOS)

### Можно ли одновременно использовать несколько серверов?

Да — большинство клиентов позволяют добавить несколько серверов и быстро переключаться между ними. Можно настроить автоматический выбор быстрейшего сервера.
