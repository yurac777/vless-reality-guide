# ❓ FAQ — Частые вопросы и решения

## О протоколе и блокировках

### Чем VLESS Reality лучше WireGuard и OpenVPN?

Коротко: WireGuard и OpenVPN **видны на уровне DPI** и блокируются ТСПУ РКН за 2 миллисекунды. VLESS Reality — нет.

Техническая причина:
- **WireGuard**: стартовый пакет Type 1 содержит жёсткий байтовый отпечаток со смещением `0x01` — ТСПУ блокирует его мгновенно
- **OpenVPN**: фиксированная длина управляющих пакетов + криптографическая сигнатура HMAC — полностью заблокирован
- **Shadowsocks**: зашифрованный хвост имеет характерную высокую статистическую энтропию — TCP Freeze через 15 секунд
- **AmneziaWG**: Junk-пакеты вычисляются по временным задержкам — частично блокируется на МТС и Ростелеком

VLESS Reality маскируется под TLS 1.3 трафик к `apple.com` или `dl.google.com`. Для ТСПУ это неотличимо от посещения сайта Apple.

### Почему соединение «зависает» вместо явной ошибки?

Это феномен **TCP Freeze** — самый коварный инструмент ТСПУ 2026 года. Вместо отправки `TCP RST` (который бы сразу сообщил об ошибке) ТСПУ **тихо отбрасывает пакеты подтверждения TCP ACK**:

```
1️⃣ Ваш ПК → SYN → Сервер          ✅
2️⃣ Ваш ПК ← SYN-ACK ← Сервер      ✅
3️⃣ Ваш ПК → ACK → [ТСПУ] → ❌ Уничтожен!
4️⃣ Ваш ПК ждёт ответа... 🧊 Заморозка
```

На экране горит «Подключено», скорость = 0 Кбит/с.

### Могут ли заблокировать VLESS Reality в будущем?

VLESS Reality маскируется под TLS 1.3 — протокол, на котором работают все банки, государственные сайты, поисковики. Заблокировать VLESS Reality = заблокировать весь HTTPS-интернет. Технически невозможно без полного отключения рунета от мирового интернета.

### Работает ли на МТС мобильном / Теле2?

Да. МТС и Т2 применяют агрессивный мобильный DPI, но VLESS Reality проходит через него как обычный HTTPS-трафик. Для максимальной совместимости с 4G/5G используйте конфиг **VLESS + XHTTP** (см. [`configs/server-xhttp-example.json`](../configs/server-xhttp-example.json)).

## Проблемы с подключением

### Не могу подключиться совсем (timeout)

1. Проверьте порт 443 на сервере:
```bash
ufw status | grep 443
netstat -tlnp | grep 443
```

2. Проверьте статус XRay:
```bash
systemctl status xray
journalctl -u xray -n 50 --no-pager
```

3. Проверьте config.json на синтаксические ошибки:
```bash
xray run -test -c /usr/local/etc/xray/config.json
```

### Подключается, но YouTube медленно грузит 4K

- Включите **Split Tunneling**: RU-сайты напрямую, иностранные через VLESS
- Выберите сервер ближе географически: Финляндия/Латвия быстрее, чем США
- Проверьте скорость самого VPS: `speedtest-cli` на сервере

### Не работает на МТС 4G в метро / на улице

МТС агрессивно применяет DPI на мобильном трафике в густонаселённых местах. Попробуйте:
1. Сменить `dest` в Reality: `www.apple.com:443` → `www.microsoft.com:443`
2. Сменить `fingerprint`: `chrome` → `firefox` или `safari`
3. Использовать конфиг VLESS + XHTTP вместо TCP Vision

### Работает дома, не работает в офисе

Корпоративные сети часто делают SSL-инспекцию. Решение:
- Используйте мобильный интернет как hotspot
- Или включите TUN-режим в v2rayN (перехватывает весь трафик на уровне ОС)

### Банковские приложения не работают с VPN

Это ожидаемо — банки блокируют зарубежные IP. Решение: **Split Tunneling** — российские домены идут напрямую, зарубежные через VLESS. Тогда Сбербанк, Тинькофф, Госуслуги работают без VPN на полной скорости.

## О клиентских приложениях

### Какой клиент лучший для Windows?

**v2rayN** — лучший выбор. Активно обновляется, поддерживает все протоколы, есть TUN-режим для перехвата всего трафика (включая приложения, которые не поддерживают системный прокси).

### Какой клиент для macOS?

- **Hiddify** (бесплатно) — [github.com/hiddify/hiddify-app](https://github.com/hiddify/hiddify-app)
- **V2Box** — App Store

### Discord работает, но голос не слышно

Discord Voice использует UDP. Убедитесь что в настройках клиента включена передача **UDP-трафика** через прокси:
- В v2rayN: Settings → Core → `"udp": true` в SOCKS inbound
- Или включите TUN-режим (перехватывает и UDP)

### Работает в браузере, но не в других программах (Telegram, Discord)

v2rayN по умолчанию настраивает только **системный HTTP/SOCKS прокси** — браузеры его подхватывают, другие программы — нет. Решение:
- Включите **TUN Mode** (Settings → TUN Mode) — требует WinTun драйвер, входит в пакет v2rayN
- Или в каждой программе вручную указать SOCKS5-прокси `127.0.0.1:10808`

## О безопасности

### Кто видит мой трафик?

- Ваш провайдер: видит зашифрованный TLS-трафик к IP вашего VPS (не содержание)
- Ваш VPS-провайдер: видит входящий трафик на порт 443 от вас и исходящий в интернет
- XRay на вашем VPS: логирует только то, что вы разрешили в `config.json` (по умолчанию — ничего)

### Логирует ли XRay мой трафик?

По умолчанию — **нет**. В конфиге `"loglevel": "warning"` пишутся только ошибки, не содержимое трафика. Полное отключение логов:

```json
"log": {
  "loglevel": "none"
}
```

### Безопасно ли использовать чужой VLESS-ключ?

Владелец сервера теоретически может видеть ваш трафик после расшифровки на сервере. Используйте только собственный VPS или доверенные сервисы.
