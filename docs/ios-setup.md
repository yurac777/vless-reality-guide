---

## Настройка через Streisand

### Способ 1: QR-код (30 секунд)

1. Установите **Streisand** из App Store
2. Нажмите **+** в правом верхнем углу
3. Выберите **«Сканировать QR-код»**
4. Направьте камеру на QR-код с вашими данными
5. Нажмите **«Добавить»**
6. Переключите тумблер → VPN активен ✅

### Способ 2: Ссылка vless://

1. Скопируйте ссылку `vless://...` (из панели или от сервера)
2. Откройте **Streisand**
3. Нажмите **+** → **«Импорт из буфера обмена»**
4. Подтвердите добавление

### Способ 3: Вручную

1. Streisand → **+** → **«Добавить вручную»** → **«VLESS»**

| Поле | Значение |
|------|----------|
| Address | IP вашего сервера |
| Port | 443 |
| UUID | ваш UUID |
| Flow | xtls-rprx-vision |
| Transport | TCP |
| Security | Reality |
| SNI | www.apple.com |
| Public Key | ваш публичный ключ |
| Short ID | ваш short ID |
| uTLS Fingerprint | Chrome |

## Настройка через Shadowrocket (если уже куплен)

1. Shadowrocket → **+** (правый верхний угол)
2. Тип: **VLESS**
3. Заполните поля аналогично таблице выше
4. В разделе **«Дополнительно»**:
   - TLS: **Reality**
   - Public Key: ваш ключ
   - Short ID: ваш short ID
5. Нажмите **«Сохранить»**

---

## Включение VPN (требование iOS)

При первом подключении iOS спросит разрешение на добавление конфигурации VPN:
1. Нажмите **«Разрешить»**
2. Введите Face ID / Touch ID / пароль
3. VPN-профиль добавлен в Настройки → VPN

---

## Split Tunneling на iOS

iOS не поддерживает нативный split tunneling для VPN-приложений, но некоторые клиенты (Streisand, Shadowrocket) имеют **«Правила маршрутизации»**:

В Streisand:
1. Зайдите в настройки сервера
2. **«Routing Rules»** → добавьте правило:
   - Domain: `geosite:ru` → Action: **DIRECT**
   - IP: `geoip:ru` → Action: **DIRECT**

## Решение проблем

**App Store не показывает Streisand (регион РФ):**
→ Зайдите в **Настройки → Apple ID → Медиа и покупки → Страна/регион**
→ Смените на Казахстан, Армению или создайте второй аккаунт с другим регионом.
→ Или используйте уже купленный Shadowrocket через второй аккаунт.

**iOS отключает VPN при переходе в фоновый режим:**
→ В настройках приложения включите **«Переподключение по требованию (On Demand)»**.

**Появляется «Небезопасная сеть» в Wi-Fi:**
→ Это нормально — iOS показывает это сообщение когда трафик шифруется через VPN.
