# 📱 Настройка VLESS Reality на Android (v2rayNG)

## Установка

Скачайте v2rayNG из Google Play или с GitHub:
- [Google Play](https://play.google.com/store/apps/details?id=com.v2ray.ang)
- [GitHub Releases](https://github.com/2dust/v2rayNG/releases)

## Способ 1: QR-код (проще всего)

1. Откройте v2rayNG
2. Нажмите **+** в правом верхнем углу
3. Выберите **«Сканировать QR-код»**
4. Отсканируйте QR-код из панели 3X-UI или от сервера
5. Нажмите ▶️ для подключения

## Способ 2: Ссылка vless://...

1. Скопируйте ссылку формата `vless://UUID@IP:443?...`
2. Откройте v2rayNG
3. Нажмите **+** → **«Импорт конфигурации из буфера обмена»**
4. Ссылка автоматически добавится
5. Нажмите ▶️ для подключения

## Способ 3: Вручную

1. Откройте v2rayNG → **+** → **«Добавить конфигурацию Vless»**

| Поле | Значение |
|------|----------|
| Псевдоним | VLESS-Reality (любое) |
| Адрес | IP вашего сервера |
| Порт | 443 |
| ID | ваш UUID |
| Flow | xtls-rprx-vision |
| Encryption | none |
| Network | tcp |
| Security | reality |
| SNI | www.apple.com |
| Fingerprint | chrome |
| PublicKey | ваш публичный ключ |
| ShortId | ваш short ID |

## Настройка Split Tunneling (рекомендуется)

Чтобы российские сайты открывались без VPN (быстрее):

1. v2rayNG → ☰ → **«Настройки»**
2. **«Тип маршрута»** → выберите **«GeoIP»**
3. **«Режим»** → **«Белый список (geosite:ru, geoip:ru — напрямую)»**

Теперь:
- ВКонтакте, Яндекс, Авито, банки → напрямую без VPN (быстро)
- YouTube, Instagram, ChatGPT → через VLESS Reality

## Проверка подключения

После включения:
1. Откройте браузер и перейдите на [2ip.ru](https://2ip.ru)
2. Должен показываться IP вашего VPS-сервера (не российский)
3. Страна должна быть той, где расположен ваш сервер

## Решение проблем

**Подключается, но страницы не открываются:**
- Проверьте правильность Public Key и Short ID
- Попробуйте другой fingerprint: `firefox` вместо `chrome`

**Иконка VPN в статус-баре, но интернет не работает:**
- Отключите IPv6 на устройстве: Настройки → Wi-Fi → Расширенные настройки

**Высокий пинг:**
- Нормально если сервер в Европе (+30-50 мс к обычному)
- Аномалия — пинг >300 мс, тогда смените сервер
