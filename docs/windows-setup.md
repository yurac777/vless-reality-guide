# 💻 Настройка VLESS Reality на Windows (v2rayN)

## Установка v2rayN

1. Перейдите на [GitHub Releases v2rayN](https://github.com/2dust/v2rayN/releases)
2. Скачайте **v2rayN-With-Core.zip** (последняя версия, около 70 МБ)
3. Распакуйте в любую папку (например `C:\v2rayN`)
4. Запустите `v2rayN.exe`
5. Иконка появится в системном трее (правый нижний угол)

## Добавление сервера

### Через QR-код или ссылку

1. Скопируйте ссылку `vless://...`
2. В v2rayN нажмите **«Сервер»** → **«Импортировать из буфера обмена»**
3. Сервер добавится автоматически

### Вручную

1. **«Сервер»** → **«Добавить [VLESS]»**

| Поле | Значение |
|------|----------|
| Псевдоним | VLESS-Reality (любое) |
| Адрес | IP вашего сервера |
| Порт | 443 |
| ID пользователя | ваш UUID |
| Flow | xtls-rprx-vision |
| Безопасность | reality |
| Тип трансляции | tcp |
| SNI | www.apple.com |
| Fingerprint | chrome |
| PublicKey | ваш публичный ключ |
| ShortId | ваш short ID |

2. Нажмите **«OK»**

## Активация системного прокси

После добавления сервера:

1. ПКМ на иконку v2rayN в трее
2. **«Системный прокси»** → **«Установить как системный прокси»**
3. Иконка станет яркой — VPN активен

Или нажмите `F6` — переключатель.

## Режим маршрутизации (Split Tunneling)

1. В v2rayN нажмите **«Настройки»** (шестерёнка) → **«Параметры маршрутизации»**
2. Выберите предустановку: **«Прямое подключение для geoip:ru»**

Это означает:
- Яндекс, ВКонтакте, Mail.ru, банки → **напрямую** (без VPN, максимальная скорость)
- YouTube, Instagram, X, ChatGPT, GitHub → **через VLESS Reality**

## Проверка скорости

Откройте [fast.com](https://fast.com) или [speedtest.net](https://speedtest.net).

Нормальные результаты при сервере в Европе:
- Загрузка: 80–95% от вашего тарифа
- Пинг: 30–60 мс (Финляндия/Нидерланды)

## Автозапуск с Windows

1. **«Настройки»** → **«Параметры»**
2. Включите **«Автозапуск при входе в систему»**
3. Включите **«Автоматически подключаться к последнему серверу»**

## Горячие клавиши v2rayN

| Комбинация | Действие |
|-----------|---------|
| `F6` | Включить/выключить VPN |
| `F7` | Переключить режим прокси |
| `Ctrl+Alt+V` | Открыть главное окно |

## Решение проблем

**Windows Defender удаляет v2rayN:**
→ Добавьте папку в исключения: Безопасность Windows → Защита от вирусов → Исключения.

**Браузер работает, а другие программы нет:**
→ v2rayN по умолчанию настраивает только системный HTTP/SOCKS прокси.
→ Для глобального захвата трафика: в настройках включите **«TUN Mode»** (требует WinTun драйвер — он в архиве с v2rayN).

**YouTube работает, но Netflix/Spotify нет:**
→ Некоторые сервисы блокируют VPS IP. Попробуйте другой IP или хостинг.
